The AIWA transplant, in four nights

Three machines, drawn in the same three positions every night, so you can see exactly what changes and what doesn't. The old ProDesk server keeps running production until the very last night — and stays bootable even after that. By the end, the Z690 becomes AIWA and the new X870E takes the desk.

BEFORE

Parts on the bench

Shopping Checked 2026-08-13 · everything arrived except the case

In hand: X870E motherboard, Ryzen 9900X, 32 GB DDR5, RTX 4060 Ti, Samsung 9100 PRO 2 TB, AIO, thermal paste, AM5 retention bracket, ASRock Challenger 850 W, PWM fan hub. Thermaltake Smart BM3 850 W stays with the Z690.

Not here yet: the Okinos Cypress 7. It's the only part that gates Friday — see the split below.

Still to buy: UPS, one more M.2 active cooler (you have one, need two), 64 GB DDR5 kit. None of these gate any night.

The case is late, so Friday splits in two. Everything that finds problems happens on the bench with the board on its own box: POST, BIOS update, Windows onto the 9100 PRO, chipset and GPU drivers, both M.2 slots verified. The drive and card pulled from the Z690 go in there too. Final mounting into the Okinos becomes a separate hour whenever it lands — dropping an already-booting build into a case is screws, not risk. Nights 2, 3 and 4 are unaffected; none of them need the X870E to be in its case.
NIGHT 1

Build the new X870E PC

One new chassis Friday, August 15 · the long night

Bench-build the X870E on the motherboard box: 9900X, AIO on the AM5 bracket, 32 GB DDR5, 4060 Ti, ASRock 850 W, and the 9100 PRO as a fresh C: with an active M.2 cooler on it. POST it and update the BIOS before anything else.

Pull the 2 TB SN7100 and the network card out of the Z690 and into the X870E. The 2 TB moves as-is — no copying, it keeps its data and becomes D:.

Clean Windows install on the Gen 5 drive, sign in to reclaim the license, then chipset and GPU drivers.

Pull the Toshiba and retire it — the Grizzly photos are already in Google Photos, so there's nothing left on it to rescue.

Leave the Z690's 1 TB SN7100 in place and blank. It's the Proxmox boot drive on Night 3.

When the Okinos arrives: transplant the finished build into it. Nothing gets re-diagnosed — it already booted.

Ends at

New PC running Windows on the bench, with the 2 TB drive attached as D:, waiting on a case. AIWA hasn't been touched.

NIGHT 2

Back everything up

No hardware touched Monday night · ~2.5 hrs, mostly unattended

Dump all four containers, and tar up the host's own config — the parts a container backup never captures.

Pull it all to the X870E's D: drive, along with the 266 GB living on the Samsung SATA drive that's being retired.

Copy the core set to the SanDisk, verify the checksums, unplug it.

Monday is deliberate: the Sunday 02:00 RAG refresh and 03:00 vzdump have both finished, so you're capturing a fresh, quiet state.

Ends at

Three copies of everything, one of them offline. Nothing on AIWA has changed.

NIGHT 3

Rehearse the Z690 → AIWA migration

Testing & validation Anytime after Night 2 · ~3 hrs if anything breaks

Wipe the 1 TB SN7100 (D: on the Z690). Boot Proxmox from a USB stick onto it — this is a test install, not the real one.

Validate the R9700 under Linux: run a test llama inference or vkmark to prove the GPU is recognized and works.

Document the exact install commands and any workarounds needed (VK_LOADER_DRIVERS_SELECT, pnputil recoveries, etc.). This becomes your Night 4 runbook.

Shut down Z690. Leave it in H5, powered off.

Ends at

Proof that the Z690 + R9700 + 1TB SN7100 can run Proxmox. No data on AIWA has changed.

NIGHT 4

Cut over to the Z690

Four approval gates Next Sunday morning · ~2 hrs active, 3–4 hrs migrations

Gate 1: Stop services on ProDesk. Run the pre-flight checks in TASK4-MONDAY-BACKUP-PLAN.md — space, SMART, free sockets.

Gate 2: Begin container restore into Z690. Watch the first LXC boot.

Gate 3: Restore the host config (network, Samba, Docker compose stacks, identity state) and verify each one boots without crashing.

Gate 4: Start llama inference on the R9700, verify latency and throughput, then update the client on X870E (change Tailscale target from ProDesk to Z690). Verify one cutover call succeeds.

Shut down ProDesk. It stays built and bootable as a rollback spare.

Ends at

Z690 is production AIWA. Llama, container workloads, and network services all running on the new host. ProDesk is cold spare. You're done.
