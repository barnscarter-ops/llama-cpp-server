# X870E First Boot After the SN7100 Arrives — 2026-08-17/18

Read this on the X870E (`cmb-workbench`). The SN7100 you just installed holds
the old Z690 `C:` — Windows, `Workspace`, everything. Here it is a **data
drive**, never a boot drive.

## Physical (done before power-on)

- 2 TB SN7100 → **M.2 slot 3**, HR-10 on it, fan → `SYS_FAN3`.
  Slot 1 keeps the 9100 PRO (stock heatsink). Slot 2 is blocked by the 4060 Ti.
- Realtek 2.5 GbE card installed (MAC `1C-86-0B-3A-48-FB`). Network config:
  `X870E-NETWORK-CUTOVER.md`. Two adapters will both say "Realtek Gaming
  2.5GbE" — identify by MAC only.

## 1. UEFI, before letting it boot

The SN7100 carries its own ESP + bootable Windows. The firmware may add or
prefer that entry. **Confirm boot order points at the 9100 PRO
("Windows Boot Manager" on the Samsung).** If the old Windows boots by
accident on this board, just power off and fix the order — don't let it sit.

## 2. Confirm the drive mounted

Expect the SN7100 as `D:` (letter may differ — substitute below). It should
mount clean because the Z690 was truly shut down (Fast Startup was verified
OFF, `HiberbootEnabled = 0`). If Windows calls the volume dirty, let chkdsk
run read-only first; don't write to it until it mounts clean.

## 3. The junction — fixes every hardcoded `C:\Workspace` path

Elevated:

```
mklink /J C:\Workspace D:\Workspace
```

`CLAUDE.md`, brain bootstrap, `recall.ps1`, runbooks, and the re-registered
scheduled tasks all resolve through it. Git/node/python follow junctions fine.

## 4. Claude config

Old config is at `D:\Users\carte\.claude` (memory, skills, hooks, keybindings).
Copy it to `C:\Users\carte\.claude` on this install (straight copy is fine),
or junction it the same way if you prefer one copy.

## 5. Environment variables

User-scope env vars did NOT travel — they lived in the old registry. Do not
copy the generated `~/.env` by hand; re-run the source of truth:

```
pwsh -NoProfile -File C:\Workspace\<consolidate-keys.ps1 location>
```

(Path resolves through the junction. Per standing rule, never promote
AI-provider API keys to user scope — they hijack subscription CLIs.)
